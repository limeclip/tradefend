# Настройка Etherscan API (история деплоера)

Etherscan (и BscScan для BSC) используется для блока **Deployer's Token History** на публичной странице токена: список контрактов, созданных тем же адресом, даты и эвристики rug / scam.

## Шаг 1. Регистрация

1. **Ethereum:** [etherscan.io](https://etherscan.io) → Sign Up.
2. **BSC:** [bscscan.com](https://bscscan.com) — отдельный аккаунт при необходимости (тот же ключ Etherscan V2 часто работает на нескольких сетях; в проекте для BSC используется `api.bscscan.com` с тем же `ETHERSCAN_API_KEY`).

## Шаг 2. API Key

1. Войдите в Etherscan.
2. **Account** → **API Keys** → **Add**.
3. Скопируйте созданный ключ.

## Шаг 3. Добавление в проект

В `.env.local`:

```env
ETHERSCAN_API_KEY=ваш_ключ_etherscan
```

## Шаг 4. Перезапуск

```bash
npm run dev
```

## Проверка

Откройте публичную страницу EVM-токена с известным деплоером. Под **Deployer reputation** должен появиться блок **Deployer's token history** с таблицей или агрегированной статистикой.

## Если ключ не задан

Отображается сообщение о том, что `ETHERSCAN_API_KEY` не настроен, без падения страницы.

## Лимиты

Бесплатный тариф Etherscan ограничивает число запросов в секунду. История деплоера кэшируется на сервере на время рендера страницы; при большом числе контрактов анализируется ограниченное подмножество.
